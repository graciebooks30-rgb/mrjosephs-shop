Sign in to edit items
Paste your GitHub access token below. It's saved only in this browser (never sent anywhere except GitHub) so you won't need to re-enter it next time. How do I get a token?
1. Go to github.com/settings/personal-access-tokens/new (while logged into the account that owns this site's repo).
2. Give it any name, e.g. "Shop Admin".
3. Under Repository access, choose "Only select repositories" and pick mrjosephs-shop.
4. Under Permissions → Repository permissions, set Contents to "Read and write".
5. Click Generate token and copy it (starts with "github_pat_").
6. Paste it below. Keep it private — anyone with it can edit this repo.
